## 💼 Projects

### 🎮 **ACE Reputation System** (Next.js + MongoDB + TypeScript)
A web app built for the CFPH gaming community — players can give reputation points to other players, view a live ranking leaderboard, and earn in-app rewards. My first project using Next.js, Better-Auth with Google provider, shadcn/ui components, and TypeScript end-to-end. Built for fun and learning; currently 90% complete.

### 🎓 **School Ticketing System** (MERN + TailwindCSS)
A full-stack solution for managing student concerns and administrative tasks. Features role-based access control, JWT authentication with httpOnly cookies, and rate-limited API protection. Started as a capstone proposal and turned into a real, working system.

### 💬 **Chat System** (MERN + WebSockets)
A real-time messenger application built to understand WebSockets and live communication from the ground up. Covers authentication and instant messaging — no fluff, just the fundamentals done right.

### 📔 **Dev Diary** (MERN + TailwindCSS)
A personal development journal with authentication where I explored TanStack Query and mutations for server-state management in React — moving beyond basic `useState` patterns.

### 🛒 **POS & Inventory System** (JavaFX)
A desktop application for managing inventory, built with Java, JavaFX, and Scene Builder. Where I learned that not everything needs to be in the cloud.
